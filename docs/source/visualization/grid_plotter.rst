Grid Plotter
============

The :class:`GridPlotter` class creates interactive Folium maps from gridded
xarray datasets with ``(time, latitude, longitude)`` dimensions. It supports
time-slider visualisation and static summary maps for any type of gridded
oceanographic or environmental data.
