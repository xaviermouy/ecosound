Environment
===========

The ``environment`` module provides classes for fetching and analysing
environmental and contextual data alongside passive acoustic recordings.
It includes interfaces for ocean models, weather reanalysis, tidal data,
lunar/solar ephemeris, ship traffic (AIS), and generic ERDDAP servers.
