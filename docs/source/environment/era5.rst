ERA5
====

The :class:`ERA5` class fetches ERA5 reanalysis data (10-m wind speed and
precipitation) for a given location and time period. Two backends are
supported: ``open_meteo`` (no registration required, default) and ``cds``
(Copernicus Climate Data Store, requires an API key).
