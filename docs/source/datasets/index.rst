Datasets
========

The ``datasets`` module provides a curated registry of bioacoustic datasets
that can be downloaded on demand and loaded directly as
:class:`~ecosound.core.annotation.Annotation` objects. Files are fetched once
and cached locally; subsequent calls return immediately from cache. Audio files
can optionally be downloaded alongside annotations.
