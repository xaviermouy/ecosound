HMD
===

The :class:`HMD` class processes Hybrid Millidecade (HMD) spectral data
stored in NetCDF files. It supports loading data from one or more deployment
directories, extracting broadband or fractional-octave band levels, and
optional Dask-based parallel processing for large datasets.
