Soundscape
==========

The ``soundscape`` module provides tools for processing and analysing
long-term soundscape data. It currently includes the
:class:`~ecosound.soundscape.hmd.HMD` class for working with Hybrid
Millidecade (HMD) spectral data stored in NetCDF files, with optional
Dask-based parallel processing for large deployments.
